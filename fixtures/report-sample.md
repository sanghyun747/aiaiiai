# TrendPilot 예제 보고서

이 문서는 합성 데이터와 mock 실행을 기반으로 한 UI/계약 예제이며 실제 SNS 유행, 실제 팔로워 변화, 실제 스폰서 실행 결과가 아닙니다.

## 계정/근거 요약

- 관측 근거는 합성 예제입니다.
- 단일 관측값은 상승 속도나 미래 유행을 증명하지 않습니다.
- 팔로워 비교 결과는 직접 언팔 원인이나 특정 게시물의 인과관계를 증명하지 않습니다.

## SAFE BET 1 — 학습 루틴 3단계

### Script

Hook: 공부를 시작하기 전에 이 순서부터 정리해 봤습니다.

Body:
1. 책상 위에 필요한 것만 남깁니다.
2. 오늘 할 일을 한 줄로 정합니다.
3. 바로 10분 타이머를 시작합니다.

CTA: 다음 비교 기록을 보려면 팔로우하세요.

### Shot List

1. 정리 전 책상과 타이머
2. 정리 → 한 줄 계획 → 타이머 시작
3. 실제 공부 장면과 다음 비교 예고

### Editing Guide

첫 4초에 결과를 먼저 보여주고 2~4초 단위의 빠른 컷으로 연결합니다. 핵심 행동만 짧은 자막으로 표시합니다.

### Thumbnail Plan

문구: 공부 시작 전 3단계

### Publishing Package

제목: 공부 시작이 늦어질 때 쓰는 3단계

목표 지표: 같은 관측 기간의 조회수와 사용자가 확인한 팔로우 전환.

## SAFE BET 2 — 공부 체크리스트

대본, 촬영 리스트, 편집 방향, 썸네일 계획, 게시 문구를 포함하는 두 번째 제작 패키지입니다.

## GROWTH EXPERIMENT — 첫 3초 Hook 개선

대상 약점: opening_hook

완성 영상만 보여주는 대신 초안 → 문제 → 수정 과정을 먼저 보여주고 첫 3초 반응 차이를 검증합니다.

## 한계

성과 기준값이 없으므로 성장 효과를 보장하지 않습니다. 실제 게시 후 동일한 관측 기간으로 직접 기록·비교해야 합니다.
