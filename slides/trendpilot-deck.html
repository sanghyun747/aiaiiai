대본, 장면, 편집, 썸네일, 게시 문구를 매번 처음부터. 1인 크리에이터는 여기서 멈춘다

팔로워 변화는 오해투성이

3
근거

03
HOW IT WORKS

관측 → 보수적 분석 → 실험 3개 → 제작 패키지 → 진짜 파일

N

Nosana가 기획한다

비식별 프로필과 허용된 출처만 보고 분석 계획과 콘텐츠 실험 3개를 씀. SAFE BET 1개 이상, GROWTH EXPERIMENT 1개 이상. 팔로워 숫자는 못 건드림

inference.nosana.com · OpenAI 호환
D

Daytona가 실행한다

고정된 Python 코드로 follower-diff와 계정명 변경 감사를 새 샌드박스에서. 제작 파일 7개도 샌드박스에서 만들어 내려받고 SHA-256으로 검증

create · upload · exec · download
✓

API가 검증한다

스키마·출처·시간 예산 체크. 패키지가 빠지면 실패, 성장 실험인데 약점 목표가 없으면 거부. 게시는 DNSimple에서 별도 동작

FastAPI 8317 · contract 1.1.0
Nosana는 Daytona를 직접 조종하지 않는다. API가 허용된 일만 한다DNSimple: sandbox 성공 ≠ 공개 도메인
